## 반도체 칩의 두 갈래

```
반도체 칩(Semiconductor Chip)
├── 메모리반도체(Memory Semiconductor)   — 데이터를 "저장"
│     ├── 휘발성(Volatile)
│     │     ├── DRAM  ← PC 메인 메모리
│     │     ├── SRAM  ← CPU 캐시
│     │     └── VRAM  ← 그래픽카드 전용 메모리
│     └── 비휘발성(Non-Volatile)
│           └── 플래시 메모리(Flash Memory)
│                 ├── NAND  ← SSD 등 대용량 스토리지
│                 └── NOR   ← 코드 실행용 임베디드 스토리지
│
└── 시스템반도체(System Semiconductor)   — 데이터를 "연산"
      ├── CPU  ← 범용 연산, 순차 처리 중심
      ├── GPU  ← 병렬 연산, 그래픽 처리 중심
      ├── NPU  ← 신경망(딥러닝) 연산 전용
      └── TPU  ← 텐서(행렬) 연산 전용
```

메모리반도체는 데이터를 **저장**하는 역할을, 시스템반도체는 데이터를 **연산**하는 역할을 맡는다. 이 저장과 연산이라는 두 축이 반도체 산업 전체를 가르는 가장 기본적인 분류 기준이다.

---

## 메모리반도체: 데이터를 저장하는 칩

메모리반도체는 전원이 꺼졌을 때 데이터가 유지되는지 여부에 따라 **휘발성**과 **비휘발성**으로 나뉜다.

### 휘발성 메모리 — DRAM, SRAM, VRAM

휘발성 메모리는 전원이 끊기면 저장된 데이터가 사라진다. 대신 읽고 쓰는 속도가 매우 빠르다.

- **DRAM(Dynamic RAM)**: PC의 메인 메모리로 쓰인다. CPU가 연산할 데이터와 명령어를 임시로 올려두는 공간이다. 커패시터에 전하를 저장하는 방식이라 주기적으로 재충전(refresh)해야 데이터가 유지된다. 회로가 단순해 대용량화·저비용화에 유리하다.
- **SRAM(Static RAM)**: CPU 캐시(L1/L2/L3)로 쓰인다. 트랜지스터 조합으로 데이터를 저장해 refresh가 필요 없고, DRAM보다 훨씬 빠르다. 대신 셀 하나를 구성하는 트랜지스터 수가 많아 집적도가 낮고 비싸서, CPU 코어 바로 옆의 소용량 캐시처럼 속도가 절대적으로 중요한 자리에만 쓰인다.
- **VRAM(Video RAM)**: 그래픽카드 전용 메모리다. GPU가 화면에 그릴 텍스처, 프레임 버퍼 같은 대용량 그래픽 데이터를 담아둔다. 최근에는 GDDR, HBM 같은 고대역폭 규격으로 발전해 GPU의 대량 병렬 연산을 뒷받침한다.

DRAM, SRAM, VRAM은 근본 원리는 같은 휘발성 메모리지만 쓰이는 자리가 다르다. DRAM은 CPU 옆에서 대용량·범용 데이터를, SRAM은 CPU 코어 바로 옆에서 소용량·초고속 캐시를, VRAM은 GPU 옆에서 그래픽 데이터를 담당하도록 최적화된 방향으로 갈라졌다.

### 비휘발성 메모리 — 플래시 메모리(NAND, NOR)

비휘발성 메모리, 즉 **플래시 메모리(Flash Memory)**는 전원이 꺼져도 데이터가 유지되는 메모리 기술이다. 스토리지의 핵심이 되는 이유다. 플래시 메모리는 셀을 어떤 논리 게이트 배열로 묶느냐에 따라 NAND와 NOR로 나뉘고, 이름도 여기서 그대로 따왔다.

- **NAND 플래시**: 셀을 NAND 게이트 배열 구조로 직렬 연결한다. 이 구조 덕분에 셀을 촘촘히 쌓아 집적도를 높일 수 있어 대용량화에 유리하고, SSD, USB, SD카드 같은 대용량 저장장치의 표준이 됐다. 페이지·블록 단위로 읽고 쓰는 특성 때문에 SSD 내부에서는 별도의 컨트롤러와 통신 프로토콜이 이 특성을 관리한다. ([[layers-of-ssd-deep-dive|Layers로 이해하는 SSD 깊이 있는 탐구]] 참고)
- **NOR 플래시**: 셀을 NOR 게이트 배열 구조로 병렬 연결한다. 셀 하나하나에 개별적으로 접근할 수 있어 임의 접근(random access) 속도가 빠르다. 대신 집적도가 낮아 대용량화에는 불리하다. 그래서 대용량 데이터 저장보다는 부팅 코드처럼 빠르게 실행해야 하는 펌웨어 저장에 주로 쓰인다. 임베디드 시스템은 하드웨어(H/W)와 그 위에서 바로 동작하는 펌웨어가 한 몸처럼 결합된 구조인데, NOR 플래시가 바로 이 펌웨어를 담아 하드웨어와 함께 부팅 즉시 실행되게 하는 역할을 맡는다.

같은 플래시 메모리라도 NAND는 "많이 저장", NOR은 "빠르게 실행"이라는 서로 다른 목적으로 갈라진 것이다.

## 시스템반도체: 데이터를 연산하는 칩

시스템반도체는 저장이 아니라 **연산**을 담당하는 Processing Unit들이다. CPU, GPU, NPU, TPU 모두 이 범주에 속하지만, 각각 최적화된 연산 방식이 다르다.

| 구분 | 연산 방식 | 강점 | 대표 용도 |
|------|-----------|------|-----------|
| **CPU** | 소수의 강력한 코어, 순차 처리 중심 | 복잡한 분기·제어 로직 처리 | 운영체제, 범용 프로그램 실행 |
| **GPU** | 수천 개의 단순한 코어, 병렬 처리 중심 | 동일 연산의 대량 동시 처리 | 그래픽 렌더링, 병렬 연산 |
| **NPU** | 신경망 연산에 특화된 회로 | 저전력 딥러닝 추론 | 스마트폰 AI 기능, 엣지 디바이스 |
| **TPU** | 텐서(행렬) 연산에 특화된 회로 | 대규모 행렬곱 연산 최적화 | 딥러닝 학습·추론 가속 |

CPU는 코어 하나하나가 복잡한 명령어를 순서대로 처리하는 데 강하고, GPU는 반대로 단순한 연산을 동시에 수천 개씩 처리하는 데 강하다. 이 구조적 차이가 GPGPU라는 개념이 등장하게 된 배경이다.

---

## GPGPU: GPU를 그래픽 밖으로 꺼내다

**GPGPU(General-Purpose computing on Graphics Processing Unit)**는 GPU를 그래픽 처리뿐 아니라 범용 연산에도 활용하는 것을 말한다.

GPU는 원래 화면의 수백만 개 픽셀을 동시에 계산하기 위해 만들어졌다. 픽셀 하나하나의 색상 계산은 단순하지만, 그 계산을 화면 전체에 걸쳐 병렬로 반복해야 한다. 단순한 연산을 대량으로 동시에 처리하는 이 능력이 그래픽 계산에만 한정될 이유는 없다. GPGPU는 여기서 출발한다.

행렬곱, 벡터 연산처럼 동일한 연산을 대량의 데이터에 반복 적용하는 작업은 GPU의 병렬 구조와 정확히 맞아떨어진다. 딥러닝의 학습 과정이 대표적이다. 신경망의 순전파·역전파는 결국 거대한 행렬 연산의 반복이고, 이를 CPU로 순차 처리하면 며칠이 걸릴 계산도 GPU로 병렬 처리하면 훨씬 짧은 시간에 끝낼 수 있다. CUDA, OpenCL 같은 프레임워크가 등장한 이유도 개발자가 GPU를 그래픽 API가 아니라 범용 연산 API로 다룰 수 있게 하기 위해서다.

GPGPU는 새로운 하드웨어가 아니라 GPU가 가진 병렬 연산 구조를 그래픽 외의 범용 문제에 적용하는 접근 방식이다. 딥러닝, 과학 시뮬레이션, 암호화폐 채굴처럼 대량 병렬 연산이 필요한 영역에서 GPU가 핵심 연산 자원으로 쓰이는 이유도 여기에 있다.

## 핵심 정리

- 반도체 칩은 크게 **메모리반도체**(저장)와 **시스템반도체**(연산)로 나뉜다.
- 메모리반도체는 휘발성(DRAM, SRAM, VRAM)과 비휘발성(NAND, NOR 플래시)으로 나뉘며, 전원이 꺼져도 데이터가 유지되는지가 기준이다.
- 시스템반도체는 CPU, GPU, NPU, TPU 등 Processing Unit을 포괄하며, 각각 연산 방식(순차 vs 병렬, 범용 vs 특화)이 다르다.
- GPGPU는 GPU의 대량 병렬 연산 구조를 그래픽 처리 밖으로 확장해 범용 연산에 활용하는 개념이다.
- GPU가 딥러닝 가속기로 쓰이는 이유는 신경망 연산이 GPU가 원래 잘하던 "단순 연산의 대량 병렬 처리"와 구조적으로 일치하기 때문이다.

작전명 AI, 코드네임 23의 두번째 미션은 여기까지다. 반도체 칩의 큰 그림을 저장과 연산으로 나눠 보고, GPU가 왜 GPGPU로 확장됐는지 이해했다면 이번 미션은 완료된 셈이다.
